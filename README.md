# Todo App

A modern Todo application built with React, Tailwind CSS, and Lucide React icons. This project is designed to help users manage daily tasks with a clean, responsive interface and interactive sound feedback.

## Project Description

This Todo app allows users to add tasks, mark them complete, update existing items, and delete tasks easily. It uses Tailwind CSS for styling and Lucide React icons for a modern UI experience. Sound effects are included for actions such as adding a task, updating a task, and deleting a task to make the app more interactive and engaging.

## Features

- Add todo items quickly
- Mark tasks as complete or incomplete
- Edit existing tasks
- Delete tasks
- Clear completed tasks
- Smooth and modern UI
- Tailwind CSS styling
- Lucide React icons
- Sound effects for add, update, and delete actions
- Local storage support for saved tasks

## Tech Stack

- React
- Vite
- Tailwind CSS
- Lucide React
- JavaScript

## Installation

1. Clone the repository
2. Install dependencies:
   npm install
3. Start the development server:
   npm run dev

## Run the App

Open the local URL shown in the terminal, usually:

http://localhost:5173
